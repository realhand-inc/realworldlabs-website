Free

Control and teleoperate your robots.

  • Robot connection and live status
  • Manual control and sensor visualization

02 / Collect

Data

Collect and manage robot data.

  • Synchronized multimodal recording
  • Egocentric capture and episode review
  • Dataset management, versioning, import and export
03 / Train

Training

Post-train VLA and RL policies.

  • Data annotation and cleaning
  • VLA: π0.5 and Isaac GR00T N1.7
  • RL locomotion: humanoid and quadruped
  • Model evaluation and versioning

Deployment

Run multiple robots on site.

  • Runtime SDK for policy-driven control
  • Motion recording and runtime playback
